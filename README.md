## 🎯 Мета роботи

Ознайомитися з основами роботи зі стеком у Windows Forms за допомогою класу System::Collections::Generic::Stack<T>, а також вивчити основні операції: додавання, видалення, перегляд елементів, перевірка на порожність і очищення стека.

## 📝 Висновки

Під час виконання практичної роботи було опановано роботу зі структурою даних стек у Windows Forms за допомогою класу System::Collections::Generic::Stack<T>. На практиці досліджено принцип LIFO та закріплено навички використання методів Push(), Pop(), Peek(), Count і Clear(). Опановано перебір елементів за допомогою циклу for each, а також реалізовано алгоритми обробки даних для числових і рядкових стеків з відображенням результатів у компонентах графічного інтерфейсу.
